**AgriConnect** is a comprehensive digital ecosystem designed to bridge the gap between farmers, traders, and agricultural experts. By integrating a dynamic marketplace with real-time communication and resource-sharing protocols, we empower the farming community with tools for sustainable growth and direct-to-consumer trade.

---

## ✨ Key Features

### 🛒 Dynamic Marketplace
*   **Direct Trade:** Buy and sell crop residue, seeds, and organic tools without intermediaries.
*   **Smart Categorization:** Easily browse through specialized categories like `Crop Residue`, `Seeds`, and `Tools`.
*   **Verified Listings:** Trust-based system with seller ratings and verified badges.

### 🚜 Resource Sharing (Rentals)
*   **Machinery Hub:** Rent high-end agricultural equipment (Tractors, Drones, Harvesters) at affordable hourly rates.
*   **Availability Engine:** Integrated calendar booking system to prevent equipment scheduling conflicts.

### 💬 Negotiation-First Communication
*   **Real-time Chat:** Direct line of communication between buyers and sellers.
*   **Offer System:** Specialized UI for making, counter-offering, and accepting prices within the chat.
*   **Media Sharing:** Share photos, locations, and documents seamlessly.

### 📊 Farmer Dashboard
*   **Sales Analytics:** Track your earnings and listing performance with intuitive charts.
*   **Inventory Control:** Manage your active products and rental equipment from a single control center.

---

## 🚀 Innovation & Patents

AgriConnect is built on an innovative architecture that goes beyond simple e-commerce. Our project features:
*   **Multi-Modal Resource Management:** A unique backend logic that handles both perpetual sales and temporal rentals in one unified flow.
*   **Localized Agri-Insights:** Real-time integration of weather and soil data to provide farmers with dynamic "Market Rate" recommendations.
*   **50-Slide UI Vision:** A comprehensive, high-fidelity user journey designed for maximum accessibility and premium user experience.

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/archana-1611/Agri_Connect.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
